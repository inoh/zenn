## はじめに

2026年6月13日、中国のZhipu AI（Z.ai）がコーディング特化の新フラッグシップ「GLM-5.2」を発表しました。「MITライセンスでオープンソース化」「100万トークンのコンテキスト」「Claude Codeにそのまま挿せる」といった見出しがSNSやニュースを駆け巡り、私も「オープンソースになったなら重みを落として試そう」とHuggingFaceを開きました。

ところが、**GLM-5.2の重み（オープンウェイト）はどこにも見つかりませんでした。**

この記事では、まず「GLM-5.2はオープンソースになった」という言説がどこまで本当なのかを一次ソースで検証し、そのうえで「では今、課金を最小限にしてどう試せるのか」「コストはどうなっているのか」を整理します。

:::message
本記事はAPIキーでの実機検証は行っていません（後述のとおり、現時点でGLM-5.2を試すには有料プランへの加入が前提になるため）。設定手順は公式・各種ドキュメントで確認した内容に基づく「未実機」の情報として提示します。実際に動かした結果は、オープンウェイト公開後に追記予定です。
:::

## GLM-5.2とは何か

公式リポジトリやモデル情報サイトで確認できる範囲では、GLM-5.2はGLM-5系列の3番目のメジャーイテレーションで、エージェント的なコーディング（agentic coding）と長時間にわたるソフトウェアエンジニアリングに最適化されたモデルです。

確認できた主なスペックは以下のとおりです。

| 項目 | 内容 |
|---|---|
| 発表日 | 2026年6月13日 |
| アーキテクチャ | 744B MoE（アクティブ約40Bパラメータ） |
| コンテキスト長 | 1,000,000トークン |
| 最大出力 | 131,072トークン |
| ライセンス（予定） | MIT |

744B MoEというパラメータ規模は、前世代のGLM-5から引き継いだものです。GLM-5の公式READMEには「GLM-4.5の355B（アクティブ32B）から744B（アクティブ40B）へスケールし、事前学習データを23Tから28.5Tトークンへ拡大した」と記載されています（[zai-org/GLM-5](https://github.com/zai-org/GLM-5)）。

なお、**ローンチ時点で公式のベンチマーク数値（SWE-bench等）は公開されていません。** 「Claude Opus級」といった比較が二次情報で飛び交っていますが、現時点では公式の裏付けがないため、本記事では性能比較には踏み込みません。

## 「オープンソース化」の真相：重みはまだ落ちていない

ここが本記事の核心です。「オープンソースになった」という情報を真に受ける前に、一次ソースで「本当に重みが公開されているか」を確認しました。結論から言うと、**2026年6月16日時点で、GLM-5.2のオープンウェイトはまだ公開されていません。**

### 検証1: HuggingFaceに重みページがない

Z.aiは過去のモデル（GLM-5、GLM-5.1）の重みをHuggingFace上でMITライセンス公開しています。

- [zai-org/GLM-5](https://huggingface.co/zai-org/GLM-5) … 公開済み
- [zai-org/GLM-5.1](https://huggingface.co/zai-org/GLM-5.1) … 公開済み

しかし、**`zai-org/GLM-5.2` に相当するモデルページは存在しません。**

### 検証2: GitHubにタグもリリースもない

公式リポジトリ [zai-org/GLM-5](https://github.com/zai-org/GLM-5) のREADMEは、執筆時点で**GLM-5.1とGLM-5までしか記載がありません**。GLM-5.2専用のリポジトリも見当たりません。

`gh` CLIでタグとリリースを確認しても、空でした。

```bash
$ gh api repos/zai-org/GLM-5/tags
[]
$ gh api repos/zai-org/GLM-5/releases
[]
```

組織全体を検索しても、GLM-5.2のリポジトリはヒットしません。

```bash
$ gh api "search/repositories?q=org:zai-org+GLM"
# → GLM-5, GLM-5.1, GLM-4.5, GLM-V ... はあるが GLM-5.2 は無し
```

### 検証3: 公式blog・docsの専用ページが404

公式ブログやAPIドキュメントの、URL規則から推測される専用ページもまだ存在しませんでした。

- `https://z.ai/blog/glm-5.2` → 404
- `https://docs.z.ai/guides/llm/glm-5.2` → 404

（比較として、GLM-5.1のブログ `https://z.ai/blog/glm-5.1` やdocsページは存在します。）

### 結論：発表と公開のタイムラグ

各種報道を総合すると、6月13日の発表で**即日利用可能になったのは後述の「GLM Coding Plan」経由のみ**で、**単体API・チャット版（chat.z.ai）・MITオープンウェイトは「翌週公開予定」**とアナウンスされています（[PC Watch](https://pc.watch.impress.co.jp/docs/news/2116962.html)）。

つまり「GLM-5.2がオープンソースになった」は厳密には**「オープンソース化が告知された」**が正確で、重みをダウンロードしてローカルで動かせるのは（予定どおりなら）6月20日前後以降ということになります。「オープンソースになったらしいから重みを探す」と私のように空振りします。

## では今、どう試すのか

重みがまだ無い以上、ローカル実行（セルフホスト）は現時点では選択肢になりません。今すぐGLM-5.2を試す唯一の経路は、**GLM Coding Planに加入してそのAPIキーを使う**方法です。

GLM Coding Planの鍵は **Anthropic互換エンドポイント**（`https://api.z.ai/api/anthropic`）を提供しているため、Claude Codeの接続先を差し替えるだけでGLM-5.2をバックエンドに使えます。これがGLM系モデルが「Claude Codeに挿せる」と言われる仕組みです。

### Claude Codeに挿す設定（未実機）

環境変数で接続先と認証トークンを差し替えます。ターミナルのセッション単位で設定するのがお試しには手軽です。

```bash
# Z.aiのCoding Planで発行したAPIキーを使う
export ANTHROPIC_AUTH_TOKEN="（あなたのZ.ai APIキー）"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Claude Codeが使うモデルスロットをGLMに割り当てる
export ANTHROPIC_DEFAULT_SONNET_MODEL="glm-5.2"
```

この状態で `claude` を起動すると、Sonnetスロットの処理がGLM-5.2に向きます。

:::message alert
上記のモデルコード `glm-5.2` は、GLM-5.1での設定パターン（`glm-5.1`）からの類推です。GLM-5.2専用のAPIドキュメントが執筆時点で未公開のため、正確なモデルコードは公開後に[公式docs](https://docs.z.ai/)で確認してください。本記事は実機での疎通確認を行っていません。
:::

疎通確認だけなら、Anthropic互換APIに直接cURLを投げる方法もあります（こちらも未実機、参考まで）。

```bash
curl -s https://api.z.ai/api/anthropic/v1/messages \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"glm-5.2","max_tokens":100,"messages":[{"role":"user","content":"あなたのモデル名は？"}]}'
```

## 気になるコストの話

ユーザーとして一番気になるのはコストだと思います。GLM-5.2まわりの料金は「プラン課金」と「従量API」の2系統で考える必要があります。

### ① GLM Coding Plan（今の現実的な入口）

GLM-5.2は全プランに追加料金なしで含まれます。各種まとめによると料金体系は以下のとおりです（四半期請求）。

| プラン | 月額換算 | 5時間あたりのプロンプト目安 |
|---|---|---|
| Lite | 約 $10 | 約80 |
| Pro | 約 $30 | 約400 |
| Max | 約 $80 | 約1,600 |

:::message
この価格・プロンプト上限は複数の第三者まとめ（[codingplan.run](https://codingplan.run/plans/glm-coding-plan)、[vibecoding.app](https://vibecoding.app/blog/zhipu-ai-glm-pricing-2026)等）で一致した数値ですが、公式の料金ページが執筆時点で参照できなかったため、加入前に必ずZ.aiの公式サブスクリプションページで最新の金額・上限を確認してください。
:::

「とりあえず試す」なら **Lite（約$10/月）** が最小コストの入口です。Claudeの定額プランと比べても、お試しのハードルはかなり低いと言えます。

### ② 単体API（従量課金）：GLM-5.2はまだ未公表

トークン従量課金でGLM-5.2を叩く料金は、執筆時点で**公式に公表されていません**（docsが404、モデル情報サイトでも価格はプレースホルダの$0.00表示）。

参考として、前世代のGLM-5.1の公式API価格は次のとおりです（[docs.z.ai](https://docs.z.ai/)）。

| モデル | 入力 | 出力 |
|---|---|---|
| GLM-5.1 | $1.40 / 1Mトークン | $4.40 / 1Mトークン |

フロンティアの商用モデルと比べると桁違いに安い水準で、GLM-5.2の従量価格もこの近辺に着地する可能性はありますが、これはあくまで推測です。確定情報は公開を待つ必要があります。

### ③ セルフホスト：現時点では不可、公開後も相応のコスト

オープンウェイトが公開されれば理論上はローカル実行できますが、744B MoEという規模はコンシューマー向けGPUで素直に動くものではありません。量子化（GGUF等）前提でも相応のVRAMとストレージが必要で、「月10ドルで試す」とは別次元のコストになります。「オープンソース＝無料で気軽に動かせる」とイコールではない点は押さえておきましょう。

## まとめ

- **「GLM-5.2がオープンソースになった」は、正確には「オープンソース化が告知された」**。2026年6月16日時点で重みはHuggingFace・GitHubのいずれにも公開されておらず、ダウンロードはできません（公開は翌週予定）。
- **今すぐ試す唯一の経路はGLM Coding Plan**。Anthropic互換エンドポイントを使い、Claude Codeの接続先を差し替えれば挿せます（モデルコードは公開後に要確認）。
- **コストは「月10ドルのLiteプランが最小の入口」**。単体API（従量）のGLM-5.2価格は未公表、セルフホストは重み公開後でも744Bゆえに軽くはありません。
- 「オープンソースになったから重みを落とそう」と動く前に、**HuggingFace・GitHubに実物があるかを自分の目で確認する**のが、こうした発表ラッシュの時期には特に効きます。

オープンウェイトが実際に公開されたら、本記事に実機検証（疎通・Claude Code連携・セルフホストの可否）を追記する予定です。
