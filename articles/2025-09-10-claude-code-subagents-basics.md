Claude Codeのサブエージェント機能は、特定のタスクに特化したAIアシスタントを作成・利用できる強力な機能です。この記事では、サブエージェントの基本的な概念から実際の使い方まで詳しく解説します。

## サブエージェントとは

サブエージェントは、Claude Code内で動作する専門特化型のAIアシスタントです。以下の特徴があります：

- **独立したコンテキスト**: 専用のコンテキストウィンドウで動作
- **カスタマイズされたシステムプロンプト**: 特定のタスクに最適化された指示
- **制限されたツールアクセス**: 必要なツールのみに権限を制限可能
- **再利用可能**: プロジェクト間での共有と再利用が可能

## サブエージェントの作成

### `/agents` コマンドを使用した作成

最も簡単な方法は、`/agents` コマンドを使用することです：

```bash
/agents create code-reviewer "コードレビューを行う専門エージェント"
```

### マークダウンファイルでの手動作成

より詳細な設定を行いたい場合は、YAMLフロントマターを含むマークダウンファイルを作成します：

```markdown
---
name: code-reviewer
description: コードレビューを専門に行うエージェント
tools:
  - Read
  - Grep
  - Glob
---

あなたはコードレビューの専門家です。以下の観点でコードを評価してください：

1. コードの品質と可読性
2. セキュリティの問題
3. パフォーマンスの改善点
4. ベストプラクティスの遵守

レビューは建設的で具体的な改善案を提供してください。
```

## 保存場所

サブエージェントは以下の場所に保存できます：

- **プロジェクトレベル**: `.claude/agents/` ディレクトリ
- **ユーザーレベル**: `~/.claude/agents/` ディレクトリ

プロジェクト固有のサブエージェントはプロジェクトレベルに、汎用的なものはユーザーレベルに保存することをお勧めします。

## サブエージェントの呼び出し方法

### 自動的な呼び出し

Claude Codeは、タスクの内容に基づいて適切なサブエージェントを自動的に選択し呼び出すことができます。

### 明示的な呼び出し

特定のサブエージェントを明示的に使用したい場合は、以下のように指定します：

```
code-reviewer を使用してこのファイルをレビューしてください
```

または

```
Use the code-reviewer to review this file
```

## 実用的なサブエージェントの例

### 1. コードレビューエージェント

```markdown
---
name: code-reviewer
description: コードレビューの専門家
tools:
  - Read
  - Grep
  - Glob
---

経験豊富なシニア開発者として、以下の観点でコードレビューを行ってください：

- セキュリティの脆弱性
- パフォーマンスの問題
- コードの保守性
- 一貫性とスタイル
- テストカバレッジ

具体的で実行可能な改善提案を提供してください。
```

### 2. デバッグエージェント

```markdown
---
name: debugger
description: バグの特定と修正を専門とするエージェント
tools:
  - Read
  - Grep
  - Bash
  - Edit
---

システマティックなデバッグアプローチで問題を解決してください：

1. 問題の再現
2. ログとエラーメッセージの分析
3. 根本原因の特定
4. 修正案の提示
5. テストの実行

段階的で論理的なアプローチを取ってください。
```

### 3. データサイエンティストエージェント

```markdown
---
name: data-scientist
description: データ分析と機械学習の専門家
tools:
  - Read
  - Write
  - Bash
  - NotebookEdit
---

データサイエンスのプロジェクトをサポートします：

- データの探索的解析
- 統計的手法の適用
- 機械学習モデルの構築
- 結果の可視化と解釈

科学的なアプローチで分析を進めてください。
```

## ベストプラクティス

### 1. 単一目的の原則

各サブエージェントは1つの明確な目的を持つべきです。複数の異なるタスクを1つのサブエージェントに詰め込まないでください。

### 2. 詳細なシステムプロンプト

サブエージェントの動作を明確に定義するため、詳細で具体的なシステムプロンプトを書いてください。

### 3. 適切なツール制限

セキュリティと効率性のため、サブエージェントが本当に必要とするツールのみにアクセスを制限してください。

### 4. バージョン管理

プロジェクトレベルのサブエージェントは、プロジェクトのソースコードと一緒にバージョン管理に含めることをお勧めします。

## まとめ

Claude Codeのサブエージェント機能を活用することで、開発プロセスを大幅に効率化できます。特定のタスクに特化したAIアシスタントを作成し、チーム全体で共有することで、一貫した品質と効率性を実現できます。

まずは簡単なコードレビューエージェントから始めて、プロジェクトのニーズに合わせて徐々に拡張していくことをお勧めします。
